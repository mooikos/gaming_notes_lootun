# Milestones & Exploration Plan

Track progression goals starting with **Phase 1: Pure Class Exploration Runs (Lv. 1 -> 100)** before re-strategizing for mid-game Ascendancies and endgame Raids.

## Phase 1 — Short-Term: Class Exploration Runs (`Lv. 1 -> 100`)

Run one dedicated save file per Base Class to learn skills, weapon types, defenses, and natural progression walls firsthand before touching crafting or hybrid party optimization.

### Exploration Rules (Per Class Save)
1. **Dedicated Class Save**: Start a fresh save focused on a single class (`Warrior` -> `Ranger` -> `Mage` -> `Paladin`).
2. **Always Push Forward**: Switch to the next Mission / Dungeon immediately whenever unlocked to feel natural offense/defense walls.
3. **No Gear Crafting Yet**: Rely purely on monster drops + QoL automation (**Barracks** auto-cast & **Scrapper** auto-salvage) so materials accumulate and focus stays on class mechanics.
4. **Stop & Snapshot at Level 100**: Upon unlocking **Ascendancies (Lv. 100)**, export the save string into `saves/`, record class impressions in `docs/classes/`, and move to the next class.

### Exploration Checklist
- [ ] **Run 1 — Warrior (`Lv. 1 -> 100`)**: Test melee/ranged weapons, armor/block mitigation, Default + Cooldown skills, and export Lv. 100 save
- [ ] **Run 2 — Ranger (`Lv. 1 -> 100`)**: Test bow/dual-wield speed scaling, evasion/dodge defense, Default + Cooldown skills, and export Lv. 100 save
- [ ] **Run 3 — Mage (`Lv. 1 -> 100`)**: Test elemental/arcane spells, barrier sustain, Default + Cooldown skills, and export Lv. 100 save
- [ ] **Run 4 — Paladin (`Lv. 1 -> 100`)**: Test blessings, block/thorns/ignite kits, Default + Cooldown skills, and export Lv. 100 save
- [ ] **Checkpoint — Re-Strategize**: Compare all 4 classes, decide whether to continue from a favorite Lv. 100 snapshot or launch a unified multi-class Main Save
