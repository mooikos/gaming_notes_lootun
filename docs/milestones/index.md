# Milestones

Track progression goals across early game, Level 100 Ascendancies, and endgame raids.

- [ ] Assemble initial roster and unlock core **Barracks** auto-cast & **Scrapper** auto-salvage upgrades
- [ ] Unlock the **Profession Hall** (`Mine`, `Forest`, `Farm`) and equip initial Profession Tools

## Mid-Term Milestones

- [ ] Reach **Level 100** on core party members and unlock **Ascendancy** classes
- [ ] Max key **Skill Masteries** (Lv. 20) and refine defensive layers for mid-game bosses & dungeons

## Long-Term Milestones

- [ ] Push **Level 150** (100 Base + 50 Ascendancy) across a full **6-player Raid roster**
- [ ] Optimize Mythic/Fated gear, Enchants, Gems, Flasks, and Relics for **Agony**, **Endless**, and **Endgame Raids**
