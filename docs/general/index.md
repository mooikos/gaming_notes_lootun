# General

## Confirmed Notes (From Gameplay)

- **Phase 1 Base Rule**: Spend gold on basic base structures during Solo `Lv. 1 -> 100` runs while keeping gear crafting disabled.
- **Automatic Profession Farming Unlock (`Tasks` + `Rubies`)**:
  - The Mission tab includes a **`Tasks`** page where completing **1 run of `Demons Lair` (`Lv. 100`)** rewards enough **Epic materials** for the automatic Profession farming upgrade (enabling passive resource collection while leveling alts).
  - Building that upgrade also requires **`Rubies`**, which unlock by completing the Task to **slay a `Lv. 101+` boss**.

## Unconfirmed / General Game Reference

> Background mechanics summarized from *Lootun* documentation & community guides (kept separate until verified in-game):
- **Default Attacks**: Automatically triggered attacks requiring a matching weapon category (`Melee`, `Ranged`, `Magic`); scale with Weapon Damage % and Attack Time.
- **Cooldown Skills & Masteries**: Active abilities automated via **Barracks** upgrades; each skill supports up to **20 Mastery Levels**.
- **Base Buildings**: `Scrapper` (auto-salvage), `Barracks` (skill auto-cast & target priority), `Profession Hall` (`Mine`, `Forest`, `Farm`), `Blacksmith`, and `Artisan`.
