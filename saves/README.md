# Lootun Copy-Paste Saves (`saves/`)

Drop exported **Lootun** plain-text save strings (`.txt` or raw text files) directly in this folder. File names can be informal/unorganized during exploration and cleaned up whenever convenient.

## Quick Export / Import Reminder
- **Export from Game**: *Main Menu* -> Select Save Slot -> **Export Save** (copies save string to clipboard) -> paste into a file here.
- **Import into Game**: *Main Menu* -> Empty Save Slot -> **Import Save** -> paste string from file.
