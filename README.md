# Gaming Notes — Lootun

Structured gaming notes, progression milestones, class builds, and crafting references for [**Lootun**](https://store.steampowered.com/app/1960270/Lootun/), hosted with Jekyll & Just the Docs (target GitHub Pages URL: `https://mooikos.github.io/gaming_notes_lootun`).

## About the Game

**Lootun** (developed by *ArrowSoftGames*) is a semi-idle incremental RPG focused on party customization, automated skill rotations, deep itemization, and endgame boss/raid progression:

- **4 Core Classes & 12 Ascendancies**: Recruit **Warrior**, **Ranger**, **Mage**, and **Paladin** adventurers and specialize each at Level 100 into 3 distinct Ascendancy classes (+50 Ascendancy levels).
- **Base & Professions**: Upgrade the **Scrapper**, **Blacksmith**, **Barracks**, **Artisan**, and **Profession Hall** (`Mine`, `Forest`, `Farm`) for automated salvaging, auto-casting, crafting, and passive material gathering.
- **Deep Endgame**: Progress through Missions, Map Expertise, Dungeons, Heroic/Agony scaling, Endless stages, and 6-player Endgame Raids.

## Local Preview

Run from the `docs/` directory:

```powershell
cd docs
bundle install
bundle exec jekyll serve
```

Then open `http://127.0.0.1:4000` in your browser.
